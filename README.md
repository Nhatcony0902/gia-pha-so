# Hệ thống quản lý gia phả số

Nền tảng số hóa gia phả (Digital Family Tree & Genealogy Platform): lưu trữ, trực quan hóa và khai thác phả hệ dòng họ, kết hợp trực quan hóa đồ thị, thuật toán tìm quan hệ, AI tạo sinh và cộng tác nhiều người dùng.

Tài liệu gốc: `docs/tai-lieu-du-an-gia-pha-so.docx` (v1.0).

## Cấu trúc repo

| Thư mục | Ý nghĩa |
|---|---|
| `specs/` | Đặc tả sản phẩm & nghiệp vụ: domain, tính năng, API contracts |
| `adrs/` | Architecture Decision Records – các quyết định kiến trúc, công nghệ, quy ước |
| `planning/` | Kế hoạch sản phẩm, backlog, sprint plan, timeline |
| `tasks/` | User stories / tasks theo sprint, trạng thái, owner |
| `src/` | Mã nguồn dự án |
| `docs/` | Tài liệu hướng dẫn, runbook, how-to, sơ đồ kiến trúc |

> **Một repo – một nguồn sự thật.** Git không chỉ để lưu code mà để lưu ý tưởng → quyết định → kế hoạch → context, để team và AI làm việc hiệu quả.

## Bắt đầu

- Đọc `AGENTS.md` để nắm luật chơi cho AI & team.
- Đọc `specs/product-vision.md` để hiểu mục tiêu sản phẩm.
- Đọc `planning/team-plan.md` để nắm kế hoạch 14 tuần và phân công FE/BE.
- Xem hướng dẫn chạy dự án trong thư mục `docs/`.
